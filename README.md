A fast, exact drop-in for csv-reader 1.0.0: it reads broken CSV files the same way, with the same errors, and returns the same answers, scanning each field in slices instead of one character at a time.

## Run it

```sh
MAKEFUN_INPUT_DIR=/input MAKEFUN_OUTPUT_DIR=/output node main.ts
```
